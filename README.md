# Slipstream

From the bench to the edge.

A launch console that records this project leaving GitHub and landing on Vercel.

- **Source:** [AnthonyHuynh1989/slipstream](https://github.com/AnthonyHuynh1989/slipstream)
- **Live:** [slipstream-launch-antonio-huynh-projects.vercel.app](https://slipstream-launch-antonio-huynh-projects.vercel.app)

Static HTML. Every push to `main` deploys.

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```
